# 🧠 Simple Quiz App

An interactive and responsive Quiz Application built using **HTML, CSS, and JavaScript**. The app presents multiple-choice questions, provides instant feedback, tracks the user's score, and allows the quiz to be restarted.

## 🚀 Features

- ✅ Multiple-choice questions
- ✅ Dynamic question rendering
- ✅ Instant correct/incorrect feedback
- ✅ Sound effects for correct and wrong answers
- ✅ Automatic score calculation
- ✅ Highlights the correct answer
- ✅ Disables options after selection
- ✅ Play Again functionality
- ✅ Fully responsive design
- ✅ Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
